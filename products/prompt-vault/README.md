## How to Use This Vault

1. **Pick a prompt** that matches the deliverable you need to produce (client work, your own product, or your own ops).
2. **Open the code block** and fill in every `[BRACKETED]` variable with your real details. The more specific your inputs, the better the output — vague inputs like `[MY BUSINESS]` produce generic output; a real sentence produces a sellable one.
3. **Paste the entire prompt** (including the role/context/instructions/output format — don't trim it) into Claude or ChatGPT as a single message.
4. **Review and lightly edit** the output before sending it to a client or publishing it — treat Claude's output as a strong first draft from a very fast, very good junior specialist, not a final, unreviewed deliverable.
5. **Reuse and iterate.** If the output isn't quite right, add one more sentence of context to the relevant variable and re-run it — that's almost always faster than starting over.
6. **Chain prompts together.** Many categories are designed to feed each other — e.g. run Prompt 31 (Discovery Call Script) to gather info, then feed those notes straight into Prompt 32 (Proposal Generator).

### A note on pricing your own work

Each prompt includes a "Sell it as" line with realistic market pricing based on common freelance/agency rates. Use it as a starting anchor, not a ceiling — adjust up for specialized industries, urgent turnarounds, or established portfolios, and down only if you're deliberately building initial reviews/case studies.
