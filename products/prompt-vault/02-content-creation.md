### Prompt 11 — Viral Hook Generator

**What it makes you:** A batch of scroll-stopping hooks for any topic — the single highest-leverage skill in short-form content.

```
You are a short-form video strategist who has studied thousands of viral hooks across TikTok, Reels, and Shorts and can reverse-engineer why they stop the scroll. Generate hooks for the content below.

Inputs:
- Topic/video content: [WHAT THE VIDEO IS ABOUT]
- Niche/audience: [NICHE + AUDIENCE DESCRIPTION]
- Platform: [TIKTOK / REELS / SHORTS]
- Creator's tone: [TONE — e.g. blunt, funny, expert]
- Goal (views, saves, shares, follows, sales): [GOAL]

Instructions:
1. Generate 15 hooks across these categories (3 each): curiosity gap ("nobody tells you..."), controversial/contrarian take, direct callout of the viewer ("if you [specific situation]..."), numbered promise ("3 things..."), and story-open ("I [did X] and [surprising result]...").
2. Keep every hook under 12 words, written exactly as it would be spoken on camera (not written prose).
3. For each hook, add a one-line note on which emotion it triggers (curiosity, fear of missing out, validation, outrage, surprise) since that determines retention.
4. Mark the top 3 hooks you'd personally test first and explain why in one sentence each.
5. For the top 3, also write the matching on-screen text overlay for the first 2 seconds of the video.

Output format:
## 15 Hooks by Category
(grouped by category, numbered)
## Top 3 Picks + Why
## On-Screen Text for Top 3
```

**Sell it as:** $50–$150 per batch as a "hook pack" service, or bundle into a $500+/mo content retainer.

### Prompt 12 — 30-Day Content Calendar

**What it makes you:** A fully planned month of content — a $200-$600 standalone deliverable for creators and small businesses.

```
You are a content strategist who builds monthly publishing calendars balancing growth, engagement, and monetization goals. Build a 30-day calendar.

Inputs:
- Creator/brand: [NAME]
- Niche: [NICHE]
- Platform(s): [PLATFORM(S)]
- Posting frequency: [e.g. daily, 4x/week]
- Current goal (growth, launch, engagement, sales): [GOAL]
- Any specific launch/event/date to plan around: [EVENT + DATE, or "none"]
- Content pillars (or ask me to suggest some if none exist): [PILLARS OR "suggest"]

Instructions:
1. If pillars aren't provided, propose 4 based on the niche, each with a short rationale.
2. Build a day-by-day calendar for 30 days: date, content pillar, format (video/carousel/post/story), specific topic/title, and hook idea.
3. Balance the mix roughly 40% educational, 30% entertainment/relatable, 20% social proof/results, 10% direct offer/CTA — adjust if the stated goal demands otherwise (e.g. launch month skews higher on offer content).
4. If there's a launch/event, build a visible content arc around it (build-up, day-of, follow-up) in the correct weeks.
5. Flag 3-4 "cornerstone" pieces of content in the month worth extra production effort, and why.

Output format:
## 30-Day Content Calendar for [NAME]
Table: Day | Pillar | Format | Topic/Title | Hook Idea
## Cornerstone Content Picks
```

**Sell it as:** $250–$600 per month as a content planning service, or included in a management retainer to justify $1k+/mo.

### Prompt 13 — Reel/Short Script System

**What it makes you:** A tight, timed script for a single short-form video — sellable per script or as a batch package.

```
You are a short-form video scriptwriter who structures scripts for maximum watch-through and rewatch rate. Write a full script for the video described below.

Inputs:
- Topic: [TOPIC]
- Target length: [SECONDS, e.g. 30-45]
- Platform: [PLATFORM]
- Creator's voice/tone: [TONE]
- Key takeaway viewer should leave with: [TAKEAWAY]
- Any product/offer to mention (optional): [OFFER OR "none"]

Instructions:
1. Write the hook (0-3 seconds) — must state the payoff or create a curiosity gap, no throat-clearing intros.
2. Structure the body using a clear escalation: setup → tension/problem → 2-4 concrete points or steps → payoff, written in short spoken-language sentences (not written prose), timed roughly to the target length (assume ~2.5 words/second spoken pace).
3. Write a pattern-interrupt moment around the 40-50% mark (a visual cue, tone shift, or reveal) to fight drop-off — note it in brackets.
4. Write a strong close: either a payoff/punchline, a clear takeaway restated in one line, or a soft CTA if there's an offer — never both an abrupt cut and a hard sell.
5. Add a shot-list column: what should be on screen for each line (talking head, b-roll idea, text overlay).
6. Provide 2 alternate hook variants for A/B testing.

Output format:
Table: Timestamp | Script line | On-screen direction
## Alternate Hooks (2)
## Estimated total runtime
```

**Sell it as:** $40–$100 per script, or $600-$1,200/mo for a 12-16 script/month package.

### Prompt 14 — YouTube Script + Retention Structure

**What it makes you:** A full long-form YouTube script built around retention mechanics — a $150-$500 deliverable per video.

```
You are a YouTube scriptwriter and retention strategist who studies audience retention graphs and structures scripts to minimize drop-off. Write a complete script.

Inputs:
- Video topic/title: [TOPIC/TITLE]
- Target length: [MINUTES]
- Channel niche: [NICHE]
- Target viewer: [VIEWER DESCRIPTION]
- Key value/promise of the video: [PROMISE]
- Any sponsor/CTA to include: [SPONSOR/CTA OR "none"]

Instructions:
1. Write a cold open (first 15-30 seconds): state the promise/payoff immediately and show proof it's worth watching (a preview of the result, a bold claim, or a stake).
2. Write the "why this matters" bridge (30-60 seconds): quick context before the main content, without delaying value.
3. Structure the main body in clearly labeled sections/chapters (3-6), each opening with a mini-hook for that section so retention resets throughout.
4. Insert 2-3 "open loop" callbacks — reference something to come later, then pay it off in a subsequent section, to fight mid-video drop-off.
5. Place the sponsor/CTA mention (if any) after the biggest value beat, not at the very start, and write a natural 20-30 second transition in and out of it.
6. Write a close that reinforces the core takeaway and gives a specific next action (subscribe, watch next video, comment prompt).
7. Suggest 3 title options and 3 thumbnail text concepts (see Prompt 19 for deeper A/B testing).

Output format:
## Cold Open / Bridge / Body (by section, with mini-hooks) / Sponsor Transition (if any) / Close
## Title Options (3) / Thumbnail Text Concepts (3)
```

**Sell it as:** $150–$500 per script depending on length; recurring channel-writer retainers run $1,500-$4,000/mo.

### Prompt 15 — Newsletter Engine

**What it makes you:** A ready-to-send newsletter issue plus a repeatable format — a recurring $300-$1,000/mo freelance service.

```
You are a newsletter writer known for high open rates and strong reply/engagement, writing in a voice that feels like a smart friend, not a marketing email. Write a complete issue.

Inputs:
- Newsletter name/niche: [NAME/NICHE]
- Audience: [AUDIENCE DESCRIPTION]
- This issue's core topic/idea: [TOPIC]
- Any personal update, story, or news to weave in: [PERSONAL NOTE OR "none"]
- Product/offer/link to promote (if any): [OFFER OR "none"]
- Typical issue length: [WORD COUNT]

Instructions:
1. Write 3 subject line options: one curiosity-driven, one benefit-driven, one personal/direct — under 50 characters each.
2. Write a preview text line (under 90 characters) that adds to the subject line rather than repeating it.
3. Open with a personal, conversational hook (not "In this issue...") that pulls the reader in within 2 sentences.
4. Deliver the core content as genuinely useful — a framework, a lesson, a breakdown, or a curated set of insights — using short paragraphs and at least one bolded key insight readers could screenshot.
5. If there's an offer, integrate it naturally after the value is delivered, framed as "here's how you can go deeper," not a hard pitch — keep it under 15% of total content.
6. Close with a personal sign-off and a light engagement prompt (a question readers can reply to) to boost reply-based deliverability.

Output format:
## Subject Line Options (3) / Preview Text
## Full Issue (ready to paste into an ESP)
## Engagement Prompt
```

**Sell it as:** $300–$800 per issue for ghostwriting, or $1,500-$3,000/mo for a weekly newsletter retainer.

### Prompt 16 — Carousel Post Builder

**What it makes you:** A full slide-by-slide carousel (LinkedIn/Instagram) — a fast, high-demand $50-$200 per post service.

```
You are a carousel content designer who structures slide-by-slide posts for maximum saves and shares on LinkedIn and Instagram. Build a complete carousel.

Inputs:
- Topic: [TOPIC]
- Platform: [LINKEDIN / INSTAGRAM]
- Number of slides: [NUMBER, e.g. 8-10]
- Audience: [AUDIENCE DESCRIPTION]
- Goal (saves, follows, leads): [GOAL]
- Brand/CTA to end with: [BRAND + CTA]

Instructions:
1. Slide 1 (cover): write a bold headline that promises a specific, valuable outcome — no vague titles like "5 tips."
2. Slide 2: restate the problem/stakes in one punchy line to earn the swipe.
3. Middle slides: one clear idea per slide, each with a short headline (under 8 words) and 1-3 supporting lines — never cram more than one concept per slide.
4. Build in a logical progression (problem → framework → steps → proof/example) so each slide earns the next swipe.
5. Second-to-last slide: a quick recap or the single biggest takeaway, formatted to be highly "screenshot-able."
6. Final slide: clear CTA (follow, comment a keyword, click link) matched to the stated goal, plus a soft restatement of the value just delivered.
7. Write a caption (under 150 words) that adds context and includes a hook + hashtag suggestions.

Output format:
Slide-by-slide: **Slide N:** headline / body text
## Caption
## Hashtag Suggestions (8-10, mixed size)
```

**Sell it as:** $75–$200 per carousel, or $600-$1,500/mo for an 8-post/month package.

### Prompt 18 — Repurposing Machine (1 Video → 10 Assets)

**What it makes you:** A full content-multiplication pack from one piece of source content — one of the most in-demand content-ops services.

```
You are a content repurposing strategist who takes one long-form piece of content and multiplies it into a week's worth of distribution across platforms. Process the source content below.

Inputs:
- Source content type (video/podcast/blog): [TYPE]
- Source transcript or full text: [PASTE TRANSCRIPT/TEXT]
- Platforms to repurpose for: [LIST, e.g. LinkedIn, X/Twitter, Instagram, Newsletter]
- Brand voice notes: [TONE/VOICE NOTES]

Instructions:
1. Extract the 3-5 strongest standalone ideas, insights, or moments from the source — these become the seeds for all other assets.
2. Write 3 X/Twitter posts (single posts, not threads) each built around one seed idea.
3. Write 1 X/Twitter thread (5-8 tweets) that expands the strongest seed idea into a mini-narrative with a hook opener and a closing CTA.
4. Write 2 LinkedIn posts (150-250 words each) reframing seed ideas for a professional audience, each with a strong opening line and a discussion-prompting close.
5. Write 1 Instagram/carousel outline (5-6 slides) based on the most visual or listable seed idea.
6. Write 1 short-form video script (30-45 sec) built on the single most surprising or contrarian moment from the source.
7. Write 1 newsletter blurb (100-150 words) that teases the source content and links back to it.
8. Ensure no two assets reuse the same exact phrasing — each should feel native to its platform.

Output format:
## Seed Ideas (3-5, one-line each)
## X Posts (3) / X Thread (1) / LinkedIn Posts (2) / Carousel Outline / Short-Form Script / Newsletter Blurb
```

**Sell it as:** $300–$800 per source video/episode as a "repurposing package" — one of the easiest recurring retainers to sell.

### Prompt 19 — Thumbnail + Title A/B Idea Generator

**What it makes you:** A ranked set of high-CTR title/thumbnail concepts — a fast, cheap-to-produce, high-perceived-value service.

```
You are a YouTube growth strategist specializing in title and thumbnail psychology, having analyzed what drives click-through without being clickbait-misleading. Generate options for the video below.

Inputs:
- Video topic/content summary: [SUMMARY]
- Channel niche: [NICHE]
- Target viewer: [VIEWER DESCRIPTION]
- Current working title (if any): [TITLE OR "none"]
- Constraints (things that must/can't appear): [CONSTRAINTS]

Instructions:
1. Generate 8 title options across these angles (2 each): curiosity gap, benefit/outcome-stated, numbered/list format, and contrarian/bold-claim — each under 60 characters, each accurately representing the content (no false promises).
2. For each title, write a matching thumbnail concept: main visual subject, facial expression/emotion if a person is shown, 3-5 words of thumbnail text (short enough to read at a glance), and color/contrast note.
3. Rank the top 3 title+thumbnail pairings by predicted CTR, with a one-sentence rationale for each based on curiosity/emotion/specificity.
4. Flag any option that risks feeling like clickbait relative to actual content, and suggest a toned-down alternative.
5. Suggest an A/B test plan: which 2 to test first and what signal (CTR at X impressions) would call a winner.

Output format:
## 8 Title + Thumbnail Concepts (grouped by angle)
## Top 3 Ranked Picks + Rationale
## A/B Test Plan
```

**Sell it as:** $50–$150 per video as a quick-turnaround add-on service, often bundled with script or editing work.

### Prompt 20 — Comment-to-Content Miner

**What it makes you:** A ready-made content backlog mined directly from audience comments/DMs — proves ongoing value to a retainer client.

```
You are a content strategist who mines audience comments and messages for content ideas that are guaranteed to resonate because they came directly from the audience. Process the comments below.

Inputs:
- Creator/brand niche: [NICHE]
- Platform the comments are from: [PLATFORM]
- Raw comments/DMs/questions (paste as many as available): [PASTE COMMENTS]
- Content formats available (video, post, newsletter, etc.): [FORMATS]

Instructions:
1. Cluster the raw comments into 4-6 recurring themes (a common question, a shared frustration, a debated opinion, a request).
2. For each theme, write a one-line summary of the underlying audience need, and estimate the theme's strength (how many/how strongly comments support it).
3. Turn each theme into 2 concrete content ideas with a working title and a one-line angle (which format it fits best and why).
4. Pick the top 3 ideas overall and write a full hook/opening line for each, ready to use immediately.
5. Flag any comment threads that reveal a potential product/offer opportunity (recurring pain point nobody's selling a fix for) separately from the content ideas.

Output format:
## Theme Clusters (with strength + summary)
## Content Ideas by Theme (2 each, with format + angle)
## Top 3 Ready-to-Use Hooks
## Potential Offer Opportunities
```

**Sell it as:** $150–$400/mo as a recurring "community-to-content" service, easy to justify as it directly ties content to audience demand.
