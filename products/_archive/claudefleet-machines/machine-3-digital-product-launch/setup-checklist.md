# Setup Checklist — Zero to First Launch

## 0. Accounts (one-time setup)

- [ ] Create a Gumroad or LemonSqueezy account, verify payout method (bank/PayPal per platform).
- [ ] Create a Resend account (or confirm existing ESP), verify sending domain if required.
- [ ] Confirm Claude Code/Claude Pro access — this runs all four agents.
- [ ] (Optional) Create a ManyChat account and connect the social account(s) you'll post from.
- [ ] (Optional) Confirm Higgsfield access if using AI-generated promo video.

## 1. Idea validation pass (researcher)

- [ ] List 2-3 candidate product ideas from your own niche knowledge or audience questions.
- [ ] Run researcher on each — do not skip this even if an idea "feels obviously good."
- [ ] Confirm each candidate has 2+ independent demand signals and 1+ comparable paid product.
- [ ] Pick the GO idea with the strongest signals and clearest gap/angle. Shelve the rest — they
      can come back next cycle if this one under-delivers or once the catalog needs variety.
- [ ] Lock the format (ebook/guide, prompt pack, template set, mini-course) and price tier
      ($9-19 / $20-34 / $35-47) based on scope, per playbook.md.

## 2. Build sprint (product-builder)

- [ ] Hand researcher's validation memo (problem statement + angle) to product-builder.
- [ ] Review the full draft against the before/after transformation — does every section earn
      its place, or is there filler?
- [ ] Resolve every `[operator: ...]` flag — insert real numbers, real testimonials, nothing
      fabricated left in the final copy.
- [ ] Format the final content for delivery (PDF export, Notion template link, video files, etc.)
      and upload it to Gumroad/LemonSqueezy as a draft listing.
- [ ] Write or generate a real cover image/thumbnail for the listing.

## 3. Pre-launch list building (marketer)

- [ ] Hand the finished product (title, promise, price, real content specifics) to marketer.
- [ ] Get the 5-email sequence, 3 social post templates, and the video prompt back.
- [ ] Load all 5 emails into Resend (or your ESP) as a scheduled sequence against the launch date.
- [ ] Schedule/queue the pre-launch social posts (Templates A and B) for the days leading up to
      launch.
- [ ] (Optional) If using ManyChat, set up the comment-to-DM automation now, pointed at the
      social account/post you'll use on launch day — test it with a dummy comment before launch.
- [ ] (Optional) Generate the promo video from the structured prompt if using Higgsfield; review
      it before scheduling — don't publish an unreviewed AI-generated video.

## 4. Launch day sequence

- [ ] Set the Gumroad/LemonSqueezy listing live at the scheduled time.
- [ ] Send Email 3 (launch day) at the planned time.
- [ ] Publish Template C (direct launch announcement) with the ManyChat trigger word if using it.
- [ ] Monitor for the first buyer questions/comments in the first few hours — route them to
      support-agent for drafted replies, review and send yourself.
- [ ] Send Emails 4 and 5 on their scheduled days; publish any remaining social posts.

## 5. Post-launch iteration

- [ ] Log every refund request and its stated reason — this is signal for product-builder's next
      cycle and for whether current listing copy over-promises.
- [ ] Log every repeated buyer question (support-agent will flag patterns) — fix the listing copy
      or FAQ section if the same question comes up 3+ times.
- [ ] Note which email/social angle drove the most clicks or replies — carry that angle forward,
      drop what didn't land.
- [ ] Add this product to the "you might also like" cross-sell line for the next product's
      launch emails — this is the catalog effect starting.
- [ ] Start the next cycle: return to Step 1 with the next candidate idea while this product's
      post-launch tail (Email 5, ongoing organic mentions) keeps running in the background.
