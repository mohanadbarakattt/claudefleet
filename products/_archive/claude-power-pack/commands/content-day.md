Topic/idea for this week's content: $ARGUMENTS

Generate a full week of social content from this single topic, in a direct-response style —
specific, benefit-led, no generic marketing filler. If a platform mix isn't specified, default to
X/Twitter, LinkedIn, and one short-form video script (for Reels/TikTok/Shorts).

## Step 1 — Mine the topic for angles

Before writing anything, break the single topic into 5-7 distinct angles so the week doesn't
read as the same post seven times. Pull from angles like:

- The core insight/lesson, stated as a contrarian or surprising claim
- A concrete before/after or result (numbers if given, otherwise structure with a placeholder)
- A common mistake related to the topic and the fix
- A behind-the-scenes/process angle ("how I actually did X")
- A question that starts a discussion
- A quick tactical tip, standalone and useful even out of context
- A story/anecdote angle if the topic supports one

## Step 2 — Write the week

Produce one content calendar with a day-by-day breakdown:

```
## Day 1 — <angle name>
**X/Twitter:** <full post text, hook-first, thread-worthy if the idea needs >280 chars — write
the thread>
**LinkedIn:** <full post, longer-form, story or insight structure, ends with a question or CTA>

## Day 2 — <angle name>
...
```

Continue through Day 7. Every post must be usable as-is — full text, not a topic outline. No
placeholders like "[insert stat here]" unless a real number genuinely wasn't provided; if a
number is missing, either write around it or mark exactly what's needed with `[NEEDS: metric]` so
it's obvious and easy to fill in, never invent one.

## Step 3 — One short-form video script

Pick the strongest single angle from the week and write a full 30-45 second script for
Reels/TikTok/Shorts:

```
HOOK (0-3s): <line that stops the scroll — specific, not generic>
BODY (3-30s): <the actual value/story, beat by beat>
CTA (30-45s): <one clear next action>
ON-SCREEN TEXT CUES: <key phrases to overlay, timed roughly to the beats above>
```

## Rules

- Every piece leads with the reader's problem or curiosity, not "excited to share."
- No emoji unless the user's usual voice uses them — check for an existing brand voice doc or
  past posts in the repo/project first; default to none if unknown.
- Vary the hook style across the week (question, bold claim, number, story opener, mistake
  callout) so it doesn't feel templated.
- End with a one-line posting-order recommendation if the platforms have different optimal days
  (e.g., LinkedIn midweek, X daily) — only if you have a real basis for it, otherwise skip it.
