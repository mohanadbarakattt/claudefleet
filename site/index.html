FAQ

The questions worth asking

Do I really need all three subscriptions?

For the full loop, yes. Claude runs the machine, Higgsfield makes the media, Postiz distributes it. You can run a reduced version — Claude only, and do the media and posting by hand — and the docs tell you which stages still work. But the machine is designed as a three-service pipeline and we're not going to pretend otherwise.

Is this just a prompt pack with a nice name?

No. It's a prompt pack plus the working parts the prompts assemble: five agent files, five skill files, a hooks config, a pipeline state model, and a real single-file admin panel that runs offline. The prompts build and operate the system; the system is what you keep.

Will this make me money?

We don't know, and anyone who tells you they do is guessing. It removes production and coordination work — what you point it at, and whether anyone wants that, is on you. There are no income claims anywhere on this page or in the products, deliberately.

Do I need to be technical?

You need to be comfortable pasting commands into a terminal and editing a JSON file. You don't need to write code — the prompts do that. If you've never opened a terminal, budget an evening for the setup doc.

What's the refund policy?

30 days, no interrogation. Install it, run it, and if it doesn't do what this page says, reply to your receipt and we refund it. That's a guarantee about your money — not a guarantee about your results.

What happens when Claude, Higgsfield or Postiz change?

Lifetime updates. When a service changes something that breaks a step, the affected prompts, skills or hooks get updated and you get the new version free — that's the whole reason it's built as swappable files instead of a black box.
